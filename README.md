## Các màn hình đã có

- Đăng nhập.
- Dashboard tổng quan.
- Quản lý tiêu chuẩn.
- Quản lý tiêu chí.
- Quản lý minh chứng.
- Quản lý người dùng.
- Thống kê phục vụ kiểm định.
- Tìm kiếm minh chứng.
- Lịch sử tải minh chứng.

## Bước tiếp theo

- Thiết kế database MySQL.
- Tạo file cấu hình kết nối PDO.
- Chuyển dữ liệu mẫu sang truy vấn database.
- Thêm đăng nhập thật bằng session và `password_hash`.
- Xử lý upload/download file minh chứng.
